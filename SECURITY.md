# Security Policy

## Supported Versions

Security updates are provided for the latest public release.

| Version | Supported |
| --- | --- |
| 1.0 | Yes |

## Reporting A Vulnerability

Please report security issues privately instead of opening a public issue.

Email: security@forkhorizon.com

Include:

- A clear description of the issue.
- Steps to reproduce.
- The macOS version and HeadsetMicGuard version.
- Any relevant logs or crash reports.

If that email is not available, open a GitHub issue with a short request for a private security contact and do not include exploit details.

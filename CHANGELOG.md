# Changelog

All notable changes to HeadsetMicGuard are documented in this file.

## 1.0 - 2026-05-21

### Added

- Menu bar app for keeping a preferred macOS input device selected.
- CoreAudio device-list and default-input listeners with debounced enforcement.
- Preferred microphone picker with built-in microphone fallback.
- Pause/Resume, Force Now, Refresh Devices, Launch at Login, and Quit menu actions.
- Custom app icon and custom menu bar status icon.
- DMG release scripts and GitHub Actions workflows.
